# Arjun Shah - Portfolio

A super minimalist dark-themed portfolio website showcasing Arjun Shah's professional presence.

## Features

- **Minimalist Design**: Clean, dark theme with focus on content
- **Responsive**: Optimized for all device sizes
- **Smooth Animations**: Subtle hover effects and page transitions
- **Social Links**: Direct links to X (Twitter), GitHub, and LinkedIn
- **Professional Photo**: Integrated profile image

## Technologies Used

- HTML5
- CSS3 (with modern features like backdrop-filter, gradients)
- Inter font family for clean typography
- SVG icons for social media links

## Getting Started

1. Clone or download the repository
2. Open `index.html` in your web browser
3. The website is ready to use!

## Customization

- Update the profile image by replacing `FireProfilePhoto.png`
- Modify social links in `index.html`
- Adjust colors and styling in `styles.css`
- Change the tagline or add additional sections as needed

## Browser Support

- Chrome (recommended)
- Firefox
- Safari
- Edge

The website uses modern CSS features but maintains good fallback support for older browsers.
